# Italics Keyboard

A custom Android keyboard that lets you type in italics, bold, bold-italic
and monospace in any app, including WhatsApp, Instagram and Notes.

## How it works
Android has no real italic in plain text, so each letter you type is swapped for
its Unicode italic twin (a becomes 𝘢). The styled text works anywhere that
accepts Unicode.

## Features
- Letters, symbols and emoji pages
- Style button: Normal, Italic, Bold italic, Bold, Mono
- Convert selected text to the current style
- Key vibration and hold-to-repeat backspace

## Limitations
- Screen readers and search can't read Unicode-styled letters properly
- Some apps and fonts show boxes instead of styled letters
- Numbers and symbols have no italic form

## Run it
1. Open the project in Android Studio
2. Run it on a phone with USB debugging on
3. In the app, enable Italics Keyboard, then select it as your keyboard
